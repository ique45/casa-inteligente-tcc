Arquitetura da
Casa Inteligente

A arquitetura da casa inteligente é baseada na integração de dispositivos eletrônicos, sensores e sistemas de controle, permitindo a automação de funções essenciais do ambiente doméstico. Esses elementos trabalham de forma conjunta para proporcionar mais acessibilidade, segurança e autonomia aos usuários.

○

Origem da Ideia

A origem deste projeto surgiu a partir da observação das dificuldades enfrentadas por pessoas com mobilidade reduzida dentro de suas próprias residências. Atividades simples, como acender uma luz ou abrir uma porta, podem se tornar desafiadoras na ausência de adaptações adequadas.

Diante dessa realidade, surgiu a proposta de desenvolver uma solução baseada em automação residencial, com o objetivo de tornar o ambiente mais acessível, seguro e funcional.

Desenvolvimento
Técnico.

O sistema é formado por quatro camadas que se comunicam em tempo real: o site (HTML, CSS e JavaScript puros, sem framework), o Firebase (autenticação, banco de dados e sincronização), um backend em Node.js publicado na Railway, e o firmware do microcontrolador ESP8266 (NodeMCU), programado em C++ na IDE do Arduino.

A cada 2 segundos, o ESP8266 consulta o backend por HTTPS, informando o estado dos sensores e recebendo os comandos pendentes — do site ou das automações. A escolha por esse ciclo curto de sincronização, em vez de um protocolo assíncrono mais complexo, prioriza simplicidade de manutenção e baixo custo de hardware, mantendo o foco em acessibilidade, segurança e facilidade de uso.

⎘

Integração de Dispositivos

Conexão entre sensores e atuadores por meio do sistema de controle, permitindo o funcionamento automatizado e eficiente da residência. Essa integração possibilita que diferentes componentes trabalhem de forma conjunta, garantindo respostas rápidas às ações do usuário e ao ambiente.

♿

Acessibilidade Testada

Contraste verificado automaticamente contra o padrão WCAG AAA (7:1), navegação completa por teclado e confirmação falada das ações em português — testado a cada alteração de código, não só no lançamento.

☁

ESP8266 (NodeMCU)

Microcontrolador com WiFi embutido, escolhido pelo baixo custo (~R$ 28) e por suportar o handshake HTTPS exigido para falar com o backend em segurança — um Arduino Uno não tem RAM suficiente para isso.

Testes e Validação

Realização de testes para garantir o desempenho do sistema e sua adaptação às necessidades dos usuários.

Programação

O trecho abaixo é o núcleo do firmware: a cada 2 segundos, o ESP8266 monta um JSON com o estado dos relés e a temperatura lida, envia por HTTPS ao backend, e aplica os comandos que ele devolver. 

void syncWithBackend() {
  secureClient.stop();

  HTTPClient http;
  http.begin(secureClient, BACKEND_URL);
  http.addHeader("Content-Type", "application/json");

  JsonDocument doc;
  doc["uid"]    = UID;
  doc["token"]  = TOKEN;
  doc["online"] = true;
  if (tempValida) doc["temperature"] = currentTemp;

  JsonObject devices = doc["devices"].to<JsonObject>();
  devices["luz"]        = estadoLuz;
  devices["ventilador"] = estadoVentilador;
  devices["portao"]     = estadoPortao;
  devices["alarme"]     = estadoAlarme;

  String body;
  serializeJson(doc, body);

  int status = http.POST(body);
  // status 200 -> aplica os comandos devolvidos pelo backend
}
